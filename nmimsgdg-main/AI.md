# AI Spatial Layout Engine Specification

## Nemotron & Ollama Integration

The AI Spatial Layout engine accepts natural language prompts from users and generates structured JSON layout actions.

### Action Schema
```ts
type LayoutAction =
  | { type: "add"; productId: string; position?: [number, number, number]; rotationY?: number }
  | { type: "move"; objectId: string; position: [number, number, number] }
  | { type: "rotate"; objectId: string; rotationY: number }
  | { type: "delete"; objectId: string }
  | { type: "duplicate"; objectId: string; quantity: number }
  | { type: "replace"; objectId: string; productId: string };
```

### Safety & Validation Rules
1. Never execute arbitrary executable JavaScript code generated by AI.
2. Validate product IDs against available inventory.
3. Clamp coordinates within room boundaries (`width / 2`, `length / 2`).
4. Validate walking clearance (minimum 0.9m).
